# kanani-website

A simple personal website built with React + Vite.

- `/` — photo, name, email, and a short bio
- `/projects` — a list of projects (placeholder data for now)

No database is used — all content lives in [`src/data/projects.js`](src/data/projects.js) and the components under `src/components`. Swap in real copy and a real photo (`public/profile.svg`, or point `Face` at a new image) whenever you're ready.

## Getting started

```bash
npm install
npm run dev
```
